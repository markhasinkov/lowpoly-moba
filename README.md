# Low-Poly MOBA ⚔️

Браузерная мини-MOBA в стиле Dota 2 с low-poly 3D-графикой. Написана на чистом JavaScript + [Three.js](https://threejs.org/), без сборки и зависимостей — открывается прямо в браузере.

![stack](https://img.shields.io/badge/Three.js-r160-black) ![type](https://img.shields.io/badge/build-none-green) ![license](https://img.shields.io/badge/license-MIT-blue)

**▶️ Играть онлайн:** https://markhasinkov.github.io/lowpoly-moba/

## Что внутри

- **Low-poly арена** — диагональная линия (лейн), река по центру, две базы по углам, деревья и камни из примитивов с flat-shading.
- **Три уникальных класса** — разные модели, тип автоатаки и собственный набор из 3 способностей:
  - **Guardian** (Танк, ближний бой) — `Q` Удар о землю (AoE), `W` Бастион (+броня и лечение), `E` Рывок-таран (рывок с уроном).
  - **Arcanist** (Маг, **дальний бой** — стреляет посохом) — `Q` Ледяная стрела (дальний снаряд + замедление), `W` Метель (большой AoE), `E` Блинк (телепорт).
  - **Stalker** (Убийца, быстрый ближний бой) — `Q` Теневой бросок (прыжок-удар), `W` Веер клинков (AoE), `E` Тень (резкое ускорение).
- **Управление** — клик = идти, клик по врагу = атаковать.
- **Прокачка способностей** (уровни 1–4): сначала **изучи** (1/2/3), потом **применяй** (Q/W/E). Наведи на иконку — описание (урон, мана, кулдаун).
- **Бой и анимации** — замахи оружием и выпады при атаке, вспышки по урону, покачивание при ходьбе, анимация смерти, всплывающие числа урона, искры и взрывы способностей, шлейф рывка, индикатор прицела для Bolt.
- **Очки умений** — по 1 за каждый уровень героя, вкладываются в Q/W/E (макс. 4).
- **Магазин артефактов** — 8 предметов за золото: урон, броня, HP, мана, реген, скорость, скорость атаки. Покупка только у своей базы (зона фонтана).
- **Инвентарь** — 6 слотов, бонусы применяются сразу.
- **Фонтан** — у своей базы быстро восстанавливает HP и ману.
- **Вражеский герой** (Crimson, Dire) с ИИ: пушит линию, фокусит цели, кастует способности, отступает при низком HP, **сам качает скиллы и закупается** по билд-ордеру.
- **Крипы** — волнами идут по линии, дерутся; **ластхит** даёт золото и опыт.
- **Лес с нейтралами** — 4 лагеря вне линии, респавнятся; фарм даёт больше золота/опыта.
- **Башни** (2 на сторону) и **троны** (базы) с автоатакой.
- **Прокачка** — до 18 уровней: рост HP/маны/урона + очко умений.
- **HUD** — HP/мана/опыт, золото, K/D, кулдауны и уровни способностей, инвентарь, миникарта, таймер.
- **Условие победы** — уничтожить вражеский трон.

## Управление

| Клавиша | Действие |
|---|---|
| ПКМ / ЛКМ | Идти / атаковать врага под курсором |
| `Q` `W` `E` | Способности (по позиции курсора) |
| `1` `2` `3` или `Shift`+`Q/W/E` | Прокачать способность |
| `B` | Открыть / закрыть магазин |
| `S` | Стоп |

## Как запустить

Из-за ES-модулей файл нельзя открыть просто как `file://` — нужен локальный сервер:

```bash
# любой из вариантов
python3 -m http.server 8000
# или
npx serve .
```

Затем открой <http://localhost:8000> в браузере (нужен интернет — Three.js грузится с CDN через importmap).

## Структура

```
lowpoly-moba/
├── index.html          # разметка + HUD + importmap для Three.js
├── css/style.css       # стили интерфейса
└── js/
    ├── config.js       # баланс, константы, цвета
    ├── scene.js        # рендерер, камера, свет, арена
    ├── entities.js     # герои, крипы, башни, базы (low-poly меши)
    ├── abilities.js    # снаряды и эффекты способностей
    ├── ai.js           # ИИ крипов, башен и вражеского героя
    ├── ui.js           # HUD, миникарта, экран конца игры
    └── main.js         # игровой цикл, ввод, бой, спавн, прокачка
```
